# 🎨 Enterprise Design System

Welcome to the official component library and interactive documentation hub for **`jowel-ahmed-design-system`**. Built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Radix UI**, and **Style Dictionary v4**.

---

## 🚀 Key Features

- **Single Repository Architecture:** Unified single-package structure built with `tsup`, `vitest`, and `storybook 8`.
- **45+ Production-Grade UI Components:** Fully accessible (WAI-ARIA), responsive, dark-mode ready components.
- **Subpath Export Optimization:** Tree-shakeable modular subpath imports (`jowel-ahmed-design-system/button`, `jowel-ahmed-design-system/date-picker`, `jowel-ahmed-design-system/form`, etc.) for optimal bundle performance.
- **Form & Schema Validation:** Built-in `react-hook-form` + `zod` schema validation primitives (`FormField`, `Field`, `FormItem`).
- **Advanced Micro-Animations:** Fluid physics spring animations powered by `framer-motion` (`FadeIn`, `SlideIn`, `ScaleIn`).
- **Design Token System:** Powered by **Style Dictionary v4** auto-generating DTCG-compliant CSS Variables and TypeScript constants.
- **Theme Engine:** Built-in `ThemeProvider` with Light, Dark, System mode, and dynamic brand accent customization (`blue` (default), `indigo`, `violet`, `emerald`, `rose`, `amber`, `cyan`, `zinc`) — try the brand switcher in the toolbar.

## 🚀 Quick Start

### 1. Import Global CSS Styles

In your root application file (`src/main.tsx` or `app/layout.tsx`):

```tsx
import 'jowel-ahmed-design-system/styles.css';
```

### 2. Wrap Application with ThemeProvider

```tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { ThemeProvider } from 'jowel-ahmed-design-system/theme';
import 'jowel-ahmed-design-system/styles.css'; // or, with Tailwind v4: @import 'jowel-ahmed-design-system/theme.css' in your CSS
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <ThemeProvider defaultTheme="system" storageKey="app-theme">
      <App />
    </ThemeProvider>
  </React.StrictMode>,
);
```
